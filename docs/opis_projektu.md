# Dokumentacja Projektu: Aplikacja do Organizacji Nauki (Student App)

## 1. Cel i Przeznaczenie Aplikacji
Projekt dotyczy aplikacji wspierającej studentów w organizacji nauki i zarządzaniu zadaniami. 
Głównym celem jest stworzenie prostego i interaktywnego narzędzia do planowania czasu i śledzenia postępów.

## 2. Rozwiązywany Problem i Odbiorca
Aplikacja rozwiązuje problem rozproszenia informacji i braku struktury w planowaniu czasu na studiach.

Docelowym odbiorcą są:
* Osoby w wieku 18–25 lat studiujące.
* Użytkownicy potrzebujący prostych narzędzi do zwiększenia produktywności i koncentracji.

## 3. Kluczowe Funkcjonalności
* **Lista zadań:** dodawanie, edytowanie, priorytetyzacja.
* **Widok kalendarza:** harmonogram dnia/tygodnia.
* **System przypomnień** i powiadomień.
* **Podstawowe statystyki** postępów.
