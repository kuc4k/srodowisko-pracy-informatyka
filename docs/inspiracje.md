# Źródła Inspiracji i Wstępne Założenia

## 1. Inspiracje i Słowa Kluczowe
* **Organizacja:** porządek, rutyna, deadliny.
* **Proces:** mikro-zadania, szybkie dodawanie, prosty UX.
* **Technologie:** offline-first, synchronizacja, integracja z kalendarzem.
* **Motywacja:** gamifikacja (streaki), statystyki motywujące.

## 2. Kluczowe Elementy Projektu
* Lista zadań (dodaj/edytuj/usuwaj, priorytety).
* Widok kalendarza i harmonogramu.
* Kategorie/tagi i filtry.
* Statystyki postępów i metryki.

## 3. Wstępne Dane Wejściowe
* **Kategorie:** Kursy, Projekty, Egzaminy, Praca domowa, Powtórki.
* **Funkcje:** dodaj zadanie, data ukończenia, przypomnienie, priorytet, powtarzanie.
* **Metryki:** liczba zakończonych zadań, średni czas realizacji.
